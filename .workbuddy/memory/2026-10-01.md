## 移动端布局溢出修复（AutoPCR_Web）

**问题**：手机端（约 412px 视口）页面横向溢出——顶部 Logo 被裁切、"清理全部日常/批量运行"按钮溢出屏幕、账号卡片右侧被裁。

**根因（3 处）**：
1. 顶部导航（`SideBar/Index.tsx`）：Logo(≈153px) + 导航图标 + 带文字"运行状态"按钮总宽 ≈470px > 视口；Logo 无 flexShrink=0 被压缩裁切。
2. Dashboard 工具栏第一行（`DashBoard.tsx`）：`HStack` 不换行，80px 固定标签 + 3 个文字按钮 min-content ≈440px > 容器。
3. 整页被撑宽：根 `Stack w="full"` 受 flex 子项 `min-width:auto` 牵连不能收缩到子元素 min-content 以下 → 整页 ≈450px → SimpleGrid 卡片列拉宽 → 卡片被裁。

**修复**：
- `SideBar/Index.tsx`：Logo Box 加 flexShrink=0、移动端 Logo 26px + maxW 40vw；`RunningStatus` 加 `compact` prop（小屏只显示图标）；header 子块加 minW=0/gap 收紧。
- `RunningStatus.tsx`：新增 `compact?: boolean`。
- `DashBoard.tsx`：根 Stack 加 `minW={0}`（关键）；工具栏两处 HStack → `Flex wrap="wrap"`；SimpleGrid `minmax(280px,1fr)` → `minmax(min(280px,100%),1fr)`；表格视图 Box 加 overflowX="auto"。

**验证方法（可复用）**：
- tsc --noEmit 通过；eslint 报错均为历史遗留，与本次无关。
- Edge headless 截图受 Windows DPI 影响，`--window-size` ≠ CSS 视口（360 物理 ≈ 477 CSS px），截图会出现"假裁切"。
- 可靠做法：`public/_debug360.html` 用 iframe 强制 CSS 视口宽度 + 遍历元素比对 `getBoundingClientRect().right > clientWidth`，`--dump-dom` 读结果。修复后 360px/320px 视口 overflowCount=0。临时文件已删除。
- vite dev server 后台启动时管道（`| head`）会导致无输出假死，直接裸跑 run_in_background；curl 需加 `--noproxy "*"`（本机系统代理会拦截 localhost 返回 502）。

**环境**：依赖用 pnpm 安装（pnpm v10.22.0）；vite base=/daily，访问路径是 `http://localhost:5173/daily/`；后端 API 代理到 localhost:13200（AUTOPCR_SERVER_HOST）。
